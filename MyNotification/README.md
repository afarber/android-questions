# MyNotification

Notification-action example simulating commands to open a nearby car or flash its lights.

## Details

The notification contains two service PendingIntent actions and an Activity intent for opening the app. RegionService handles the simulated actions and returns feedback; no vehicle connection is implemented.

This is a legacy Eclipse/ADT project. Its declared SDK and library references are in [project.properties](project.properties).
