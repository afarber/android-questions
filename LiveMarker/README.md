LiveMarker
==========

Java / XML app with [OpenMapView](https://github.com/afarber/OpenMapView), showing a drawable marker at the device's live location. The XML shape has an explicit size and is anchored at its center. New location fixes move the same marker; the camera centers only on the first fix, and the Center button returns to the latest position.

Answer to the Stack Overflow question [How to Add Marker in osmdroid?](https://stackoverflow.com/q/55705988).
