# PickLocation

Java map form filling longitude and latitude fields from a tap on OpenMapView.

## Details

The form includes a name for the selected stop and separate coordinate fields. A map tap supplies the geographic position, avoiding manual entry of the longitude and latitude.

Map rendering uses [OpenMapView](https://github.com/afarber/OpenMapView).

Answer to the Stack Overflow question [Set onclicklistener for MapView using open street map](https://stackoverflow.com/q/67850072).
