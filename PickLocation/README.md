PickLocation
============

Java app with [OpenMapView](https://github.com/afarber/OpenMapView), which fills the longitude and latitude fields of a form when the user taps the map, with `setOnMapClickListener()`. A marker shows the picked location and moves with every tap.

Answer to the Stack Overflow question [Set onclicklistener for MapView using open street map](https://stackoverflow.com/q/67850072).
