NavigationOffset
================

Java app with [OpenMapView](https://github.com/afarber/OpenMapView), which shows the current location near the bottom of a heading-up map in navigation mode, so that more of the road ahead is visible. A top map padding with `setMapPadding()` moves the camera target down, and the map turns around it with the camera bearing. A button switches to a centered north-up overview.

Answer to the Stack Overflow question [osmdroid: animate to current location with pixel offset](https://stackoverflow.com/q/74046688).
