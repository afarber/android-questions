TwoPointLine
============

Java / XML app with [OpenMapView](https://github.com/afarber/OpenMapView), drawing a red polyline between two fixed Berlin coordinates. Pan and zoom the map, or use **Fit endpoints** to restore the overview. The line connects the coordinates directly; it is not a calculated road route.

Answer to the Stack Overflow question [How can draw a line (Polyline) in Android studio in OSM?](https://stackoverflow.com/q/51068005).
