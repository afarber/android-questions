# QRScanner

Java example launching ZXing Barcode Scanner and displaying a scanned code or cancellation result.

## Details

IntentIntegrator starts the external scanner and parses the returned intent. The Activity shows a result dialog, including the case where the user cancels without scanning a barcode.

This is a legacy Eclipse/ADT project. Its declared SDK and library references are in [project.properties](project.properties).
