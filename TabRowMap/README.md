TabRowMap
=========

Kotlin / Jetpack Compose app with [OpenMapView](https://github.com/afarber/OpenMapView) in the first tab below a TabRow, which stays visible and keeps the map position when switching tabs.

Answer to the Stack Overflow question [Android Jetpack Compose open street map conflict with tabrow](https://stackoverflow.com/q/76161027).
