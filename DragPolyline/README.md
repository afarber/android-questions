DragPolyline
============

Java app with [OpenMapView](https://github.com/afarber/OpenMapView), which draws a polyline with a draggable marker at each point. The line follows a marker while it is dragged, with `setOnMarkerDragListener()` and `Polyline.setPoints()`, and a long press on the map adds a point.

Answer to the Stack Overflow question [Drag polyline along with marker in openstreetmap?](https://stackoverflow.com/q/50442658).
