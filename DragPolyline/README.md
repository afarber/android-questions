# DragPolyline

Java map example reshaping a polyline by dragging markers at its vertices.

## Details

Each draggable marker represents one point in the line. Moving a vertex updates the polyline coordinates so the displayed geometry follows the markers.

Map rendering uses [OpenMapView](https://github.com/afarber/OpenMapView).

Answer to the Stack Overflow question [Drag polyline along with marker in openstreetmap?](https://stackoverflow.com/q/50442658).
