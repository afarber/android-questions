DragPolyline
============

Java app with [OpenMapView](https://github.com/afarber/OpenMapView), which draws a polyline with a draggable marker at each point. A marker can be dragged right away or after a long press on it, and the line follows it while it moves, with `setOnMarkerDragListener()` and `Polyline.setPoints()`. A long press on the map adds a point.

Answer to the Stack Overflow question [Drag polyline along with marker in openstreetmap?](https://stackoverflow.com/q/50442658).
