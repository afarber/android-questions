# ZXingTestActivity

ZXing test application exercising Barcode Scanner intents, result handling, and barcode benchmarks.

## Details

The project includes test actions and a separate benchmark Activity with asynchronous result collection. It is ZXing project code with Apache 2.0 notices retained in the source.

This is a legacy Eclipse/ADT project. Its declared SDK and library references are in [project.properties](project.properties).
