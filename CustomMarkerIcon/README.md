CustomMarkerIcon
================

Java app with [OpenMapView](https://github.com/afarber/OpenMapView), which shows the approximate stops of the bus line 100 in Berlin with a custom round icon from a vector drawable. The icon is anchored at its center, so it sits on the route. The button switches to the bottom anchor of a pin, which makes the icons float above the route.

Answer to the Stack Overflow question [customized icon in osmdroid marker android](https://stackoverflow.com/q/60301641).
