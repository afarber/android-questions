# CustomMarkerIcon

Java map example displaying bus-stop markers with a custom round drawable anchored at its center.

## Details

The drawable supplies the marker image, and the anchor places its center on the geographic coordinate. The example uses OpenMapView markers to separate icon appearance from marker position.

Map rendering uses [OpenMapView](https://github.com/afarber/OpenMapView).

Answer to the Stack Overflow question [customized icon in osmdroid marker android](https://stackoverflow.com/q/60301641).
