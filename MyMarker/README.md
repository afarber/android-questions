# MyMarker

Legacy Google Maps example adding markers for Hamburg and Kiel, including a custom icon.

## Details

The Activity adds a normal marker for Hamburg and a customized marker for Kiel. This is an embedded Google Maps experiment using the legacy Maps integration and its project configuration.

This is a legacy Eclipse/ADT project. Its declared SDK and library references are in [project.properties](project.properties).
