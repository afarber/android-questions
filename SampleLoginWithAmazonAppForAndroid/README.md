# SampleLoginWithAmazonAppForAndroid

Login with Amazon sample requesting profile access and displaying the signed-in user's details.

## Details

The Activity supports login, logout, authorization callbacks, and returning from the account flow. Its included SDK and application registration must match the intended Login with Amazon setup.

Sample from the Login with Amazon documentation; the original SDK and source notices are retained.
