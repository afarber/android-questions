InfoWindowClick
===============

Java app with [OpenMapView](https://github.com/afarber/OpenMapView), which opens a dialog when the user taps the info window of a marker, with `setOnInfoWindowClickListener()`. A tap on a marker opens its info window, a tap on the map closes it.

Answer to the Stack Overflow question [Click Event on InfoWindow at Osmdroid Marker](https://stackoverflow.com/q/73627044).
