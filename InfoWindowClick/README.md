# InfoWindowClick

Java map example opening a dialog when a marker's info window is tapped.

## Details

A marker click exposes the info window, and a separate info-window callback opens the dialog. The example distinguishes clicking the marker from clicking the information displayed above it.

Map rendering uses [OpenMapView](https://github.com/afarber/OpenMapView).

Answer to the Stack Overflow question [Click Event on InfoWindow at Osmdroid Marker](https://stackoverflow.com/q/73627044).
