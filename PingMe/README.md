# PingMe

Notification sample scheduling a reminder with editable text and snooze and dismiss actions.

## Details

MainActivity starts PingService with the chosen delay and message. The service builds a notification with action intents and a result Activity. Original Android Open Source Project Apache 2.0 notices remain in the source.

This is a legacy Eclipse/ADT project. Its declared SDK and library references are in [project.properties](project.properties).
