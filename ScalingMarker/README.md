ScalingMarker
=============

Java app with [OpenMapView](https://github.com/afarber/OpenMapView), which shows "markers" sized in meters instead of pixels, so they grow and shrink with the zoom: a ground overlay 60 m wide and a circle with a radius of 60 m. Both are clickable. A normal `Marker` keeps its size in pixels, for comparison.

Answer to the Stack Overflow question [Custom Marker in OpenStreetMap](https://stackoverflow.com/q/76817554).
