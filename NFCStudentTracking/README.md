# NFCStudentTracking

NFC student-transport example reading tag data to maintain a group of students and display it in a list.

## Details

The transportation Activity handles NDEF discovery, parses student information, and updates the group. A separate web-service screen is included; the sample needs suitable NFC tags and hardware for its tag-reading flow.

From [Professional NFC Application Development for Android](http://www.wrox.com/WileyCDA/WroxTitle/Professional-NFC-Application-Development-for-Android.productCd-1118380096.html).

This is a legacy Eclipse/ADT project. Its declared SDK and library references are in [project.properties](project.properties).
