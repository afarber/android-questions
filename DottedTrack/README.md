# DottedTrack

Java map example drawing the same GPX track as a solid, dashed, or dotted polyline.

## Details

The track geometry is reused while its stroke pattern changes. It demonstrates OpenMapView polyline styling without changing the route coordinates.

Map rendering uses [OpenMapView](https://github.com/afarber/OpenMapView).

Answer to the Stack Overflow question [Is there a way to draw dotted line using osmdroid polyline on osm map?](https://stackoverflow.com/q/56685476).
