# GoogleAuth

Multi-provider sign-in example combining Google, Facebook, VK, and Odnoklassniki account flows with local user data.

## Details

The Activity handles provider callbacks and updates the user model and profile display. Provider app registrations and app/google-services.json are needed for the configured integrations; see the [developer console](https://console.developers.google.com). The sample also includes database and WebSocket code.
